# 可视化 pandas 工作台 · Visual pandas Workbench

《可视化导论》第三次作业。用可视化方式实现 pandas 的常用数据操作，中英双语。

## 本地运行

直接双击 `index.html` 即可（全部为本地资源，无构建步骤、无 CDN 依赖、无框架）。
也可以用静态服务器：

```sh
python -m http.server 8768
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 布局与主题（深色科幻风：极光背景、网格漂移、扫描线） |
| `viz.css` | 图形样式 |
| `df.js` | 迷你 pandas 引擎：读取/选择/筛选/排序/缺失值/类型/描述统计/分组/透视/相关/滚动/分箱/重采样/合并/拼接/重塑，含不使用 eval 的表达式解析器 |
| `data.js` | 默认示例数据集（固定种子，可复现；含故意注入的缺失值与重复行） |
| `charts.js` | 可视化库：柱状/分组柱/堆叠柱/折线面积/散点/气泡/直方/箱线/热力/环形/矩形树/雷达/缺失矩阵/小倍数/连接图 |
| `i18n.js` | 中英双语字典 |
| `app.js` | 工作台：操作流水线、参数面板、代码回显、数据表、图形推荐与联动 |

## 设计要点

- **图形即入口**：柱子、环扇、树块、热力格、直方分箱都可以直接点击或框选，
  被点中的类别/区间会作为新的筛选步骤插入流水线最前面（先筛基础数据，再重新聚合）。
- **一动一图**：每一步操作都同时产出结果数据、等价 pandas 代码、以及能观察这一步的图形。
- **配色分层**：分类用 10 色亮色板，量级用「暗底→亮青」顺序色阶，相关/差值和用「品红↔青」发散色阶；
  热力格的文字颜色按格子实际底色的亮度自动选深/浅，保证任何一格都看得清。
- **不做被拉伸的图**：每张图都带固有宽度，只允许等比缩小、不允许放大，避免放大后字虚、行距失控。
- **中英一致**：图形内部的提示框、图例、占位文案也全部走同一份字典，切到英文不会残留中文。

## 说明

- 所有计算在浏览器内完成，数据不会上传。
- 内置数据是**示例数据**，仅用于演示操作，不代表任何真实结论。
- 站点为纯静态，可直接部署到 GitHub Pages（根目录）。
